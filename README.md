# 🎓 Teachers’ Day Message Card — Sir Randy Bello

An interactive digital greeting card created to celebrate and honor **Sir Randy Bello**, our Web Development instructor. This project expresses gratitude through a personalized appreciation letter, elegant design, and interactive features inspired by the creativity of web development.

🌐 **Live Website:** https://alvinfajardo2007-star.github.io/BSIS2B/

## 📖 Project Features

- 💌 **Interactive Letter** – Open and close a personalized Teachers’ Day appreciation letter.
- 🎨 **Elegant Design** – A clean and professional layout created for a meaningful tribute to our instructor.
- 🌓 **Light Mode** – Switch the website to light mode for a different viewing experience.
- ✨ **Interactive Effects** – Enjoy interactive elements that make the greeting card more engaging.
- 💻 **Web Development Theme** – Includes a message appreciating Sir Randy Bello’s lessons in HTML, CSS, JavaScript, and problem-solving.
- 📱 **Responsive Experience** – Designed to be viewed through a web browser on different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Structures the webpage and its content.
- **CSS3** – Styles the layout and visual presentation.
- **JavaScript** – Supports interactive features and user actions.

## 🚀 How to Use

1. Open the live website: https://alvinfajardo2007-star.github.io/BSIS2B/
2. Read the Teachers’ Day greeting for Sir Randy Bello.
3. Click **Open the Letter** to view the full appreciation message.
4. Use the **Light Mode** button to change the appearance.
5. Click **Send a Little Thanks** to interact with the greeting card.
6. Click **Close Letter** to close the letter.

## 🎯 Purpose of the Project

The purpose of this project is to create a creative and meaningful digital greeting card for Teachers’ Day while demonstrating practical skills in web development. It combines a personalized message with interactive webpage elements to show appreciation for an instructor who helps students learn, improve, and develop their programming skills.

## 💡 Learning Outcomes

Through this project, students can practice:

- Creating webpage structures using HTML.
- Styling and organizing content using CSS.
- Adding interactive behavior using JavaScript.
- Designing a user-friendly website.
- Combining creativity and technology to communicate a meaningful message.
